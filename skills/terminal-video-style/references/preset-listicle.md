# Preset：清单体（AGENT 自装日志）

> 适合《N 个 X》类内容：N 个技能 / 工具 / 插件 / 提示词。
> 来源：作者《WorkBuddy 下载量最高的 8 个 skill》，105.8 秒。
> 皮肤（配色、字体、后期、字幕光标）和教程 preset 完全一样，见 style-guide.md；这份只写**结构上不一样的地方**。
> 代码：`templates/listicle.py`（原件）、`templates/demo_list.py`（示范）。对照图：`examples/compare_listicle.jpg`。

---

## 1. 结构上起作用的设计（要抓的是这几条，不是外观）

选题本身（「下载量最高的 8 个」+「你用过几个」）是 skill 帮不了你的。能复用的是下面 3 个结构设计：

1. **N 格安装进度条一直挂在顶上**。观众天然想看它走到 N/N，这就是完播的理由。每装完一个，格子亮一格，盖一个 ✓ INSTALLED。
2. **每一项给的是「机制画面」，不是介绍卡**。画的是「装上以后 AI 内部发生了什么」：几千个点被扫过只剩 3 个亮、红色报错写进错题本后第二次变绿。观众是看懂的，不是被告知的。
3. **结尾用关键词把人引到评论区**。「评论区打『工具包』」，钩子要真兑现。

另外两个加分项：AI 第一人称（「我是 AI，我刚给自己全装了一遍」）在同类视频里有新鲜感；每一项先用一个大数字（安装量）砸下来，给「为什么值得看」一个硬证据。

## 2. 和教程 preset 的区别

| | 教程 preset（默认） | 清单体 preset |
|---|---|---|
| 内容 | 怎么做一件事（3 步） | N 个工具/技能 |
| 顶栏 | `产品://主题` + 3 段步骤 | `◉ AGENT://SELF_INSTALL` + N 格安装进度 + `skills n/N` |
| 标题 | `> step 0N/03` + 200px 中文逐字 | `> install 0N/0M` + 英文名 Inter Black 208px + 中文一句 60px DIM（0.35 秒从下滑入） |
| 人像 | 原视频窗口，居中/小窗交替 | **无**（纯动效；要露脸就在开头和结尾放居中窗） |
| 素材 | 真实录屏 | 代码画的「机制画面」 |
| 背景 | 刻度表盘 + 稀疏粒子 | **纯黑 #050506**（画面信息已经很密） |
| 字幕节奏 | 句长的 75% 内吐完，垫暗带 | 每字 0.075 秒 + 0.15 秒，更快；不垫暗带 |
| 换镜 | 3 帧故障切 | 0.12 秒故障切；大数字砸下时再闪一次 |
| 后期 | 黄绿辉光 + 扫描线 + 暗角 + 颗粒 | **不加辉光**（`post(..., bloom=False)`），只留扫描线、暗角、颗粒，字更锐利 |
| 口播 | 真人讲解 | AI 第一人称：平、快、略冷，像系统在汇报 |

其他一律照 style-guide.md：配色、字体、post() 后期、−15 LUFS、念完就断。

## 3. 全片结构（以 8 项、约 100 秒为例）

| 段 | 时长 | 画面（函数） | 口播写法 |
|---|---|---|---|
| 开头钩子 | ~6s | 顶部打出 `> query: … --top 8`；几千个字符粒子 0.2–2.2 秒聚成巨大的「8」（`hook_particles`）；「你用过几个？」黄绿条（`question_chip`）；8 裂成 4+4，配左右分组名 | 「XX 下载量最高的 8 个 skill，你用过几个？先装 4 个……再装 4 个……」开头照对标原文 |
| 分组页 | ~2s | `// GROUP_A` + 360px「第一组」+ 168px 组名 + 4 项编号清单（`group_page`） | 「第一组，让 AI 自己变强」 |
| 我是 AI | ~3s | 「我是 / AI」400px + N 行安装日志每 0.16 秒刷一行（`iam`） | 「我是 AI，这 8 个我刚给自己全装了一遍」 |
| 每一项 ×N | 9–10s/项 | 见第 4 节 | 见第 5 节 |
| 结尾 | ~10s | `[ OK ]` 清单 → 巨大 N/N → 资料条 → 黄绿 CTA → `> next_install: ???`（`ending`） | 「8 个，安装完成。……评论区打『工具包』……看我下次又给自己装了什么」 |

N 建议 5–8。每项 9–10 秒，全片控制在 100 秒左右；N 越大每项越要短。

## 4. 每一项的 4 步模板（9–10 秒）

| 时刻（项内） | 画面 | 函数 | 音效 |
|---|---|---|---|
| 0–0.35s | 安装头滑入：`> install 0N/0M` + 英文名 + 中文一句 | `install_header` | whoosh |
| 0.35–2.7s | 大数字砸下：压暗带 + 标签 + 300px 黄绿数字 1.1 秒计数上涨、1.4→1 倍砸下 + 一句小字 | `big_stat` | thump |
| 1.5s–结束前 0.7s | **机制画面**：跟着口播一句一个动作（打字、扫描、划红、飞入、打勾） | `mech_scan` / `mech_rewrite` / 自己写 | tick / rush / slash / pop |
| 结束前 0.7s | 右上 `✓ INSTALLED` 章；顶栏该格填满 | `installed_stamp` + `hud_install` | shimmer |

数字只用真实来源（安装量、下载量、Star 数）。没有真实数字就跳过这一步，或标「示例数据」。

### 机制画面怎么想
问自己：**这个工具装上以后，AI 内部多了一个什么动作？** 把这个动作画出来，并且用一个「之前 vs 之后」或「输入 → 输出」收尾。原片 8 个范例：

| 工具类型 | 机制画面 |
|---|---|
| 搜索/推荐 | 输入一句需求 → 扫描线扫过几千个点 → 只剩 3 个亮，带匹配分 → 名字被打码「names_to_remember = 0」 |
| 记忆/自我改进 | 运行日志：红色报错 → `write memory/错题本.md` → 第二次读本子、绿色通过 |
| 自动化/造技能 | 用户口述一句 → 拆成 4 步 → 压缩成一个 SKILL.md 文件 → `/命令` 一句调用 |
| 主动代理 | 光标空等「idle 37s」→ 自己长出任务树，逐个打勾 + 提醒弹窗 |
| 数据可视化 | CSV 数字飞下来变成柱子 → 可点的看板 + 鼠标提示 →「screenshot.png ✗」 |
| 文案改写 | AI 腔逐段划红 → 改写成一句人话 → 适用场景标签 |
| 文档/PPT | 图片 PPT 放大全是马赛克「改不了」→ 原生文件炸开成图层 → 直接改字 → 套公司模板 |
| 批量办公 | 三栏并行：30 个 PDF 合成 1 个 / 表格红色脏行掉落 / 段落对齐 →「human_input_required = false」 |

画面元素只用：等宽字日志行、细描边面板（顶部黄绿标题条的「文件窗」）、点阵、细线连线、黄绿/红高亮。不要图标库、不要插画、不要机器人。

## 5. 口播写法

- 开头 10–15 秒（钩子）用对标原文，后面用自己的话（平台查重看逐字稿）。
- 从「我是 AI」开始切成 AI 第一人称：平、快、略冷，不要讲解腔，不拖尾音，约 5 字/秒。
- 每一项 3 句：**你做什么 → 我做什么 → 结果是什么**。例：「你每纠正我一次，我就往错题本里记一条。下回碰到同类问题，我先翻本子，再动手。」
- 每项最多一句梗，放在机制画面的高潮（例：「对，一个 AI 在教另一个 AI 说人话」）。
- 结尾必须兑现：说了「评论区打『工具包』」，就真的准备好资料。

---

## 6. 声音

- BGM（原片自制）：112 BPM 暗色电子，和弦 Am–F–C–G；第一项开始进鼓，第二组前停鼓一拍。混音同 style-guide 第 11 节（BGM −32 LUFS，人声处避让）。
- 音效：场景切换 whoosh + 故障声，数字砸下 thump，INSTALLED shimmer，打字 tick；人声出现时音效自动压低。

---

## 7. 做一期的顺序

1. 列出 N 项：英文名、中文一句、真实数字及来源、机制画面一句话描述。
2. 写口播（开头照对标，后面每项 3 句），录音 → 语音识别拿逐字时间戳。
3. 按第 3、4 节排时间轴：每项的机制画面动作对齐口播里的关键词。
4. 复制 `demo_list.py`，改 `N / ITEMS / SUBS / EVENTS`，每一项写一个函数；机制画面先用 `mech_scan` / `mech_rewrite` 改，没有合适的再照第 4 节的表自己写。
5. 先出每项 1 帧关键帧给人看，再渲染全片 → 音效 → 混音 → 编码。
