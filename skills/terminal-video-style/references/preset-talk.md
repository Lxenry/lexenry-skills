# Preset：口播教程（真人讲 + 录屏/动效）

> 适合：真人出镜讲怎么用一个工具，中间穿插录屏和动效。
> 来源：作者两期作品。
> - 《WorkBuddy 接 G站》：4K 终端风，71.5 秒。人像大窗在左，右栏放讲解卡，人像下方有示波器。讲操作时人像缩到右下小窗。混音参数就是 style-guide 第 11 节那套。
> - 《WorkBuddy 做 PPT》：45.4 秒。人像居中和小窗交替，背景是流动光带 `ribbon`。巨型输入框跟着口播逐字打出提示词，然后纸飞机发送，进入下载/安装/验证三节点。转折句人像居中，背后放速度线，盖「划重点」章。
> 皮肤照 `style-guide.md`（第 8 节「人像」写的就是这个结构）。
> 代码在 `templates/termstyle.py`（`cam_window` / `CAM_CENTER` / `CAM_PIP`）和 `templates/talk.py`。
> 示范：`templates/demo.py`（成品先行 / 录屏面板 / 人像居中）、`templates/demo_talk.py`（左右分栏 / 巨型输入框 / 速度线）。

## 1. 人像的三个位置

| 位置 | rect（4K） | 什么时候 | 同屏的东西 |
|---|---|---|---|
| 左侧大窗 | (120, 840, 912, 1216) | 讲为什么、讲概念（《接 G站》前半） | 右栏 x 1100–2040：讲解卡、打字行（`typed_lines`）；人像下方示波器（`scope`） |
| 居中 | (432, 730, 1296, 1680) | 结论、转折、强调句 | 背后动态背景，转折句加 `speedlines()` + `mark()` 红章 |
| 右下小窗 | (1584, 2150, 456, 608) | 讲具体操作 | 主画面给录屏/动效；字幕挪到小窗左边 |

- 位置切换用 0.45–0.5 秒 eio 插值（`cam_rect(k)`）。
- 人像永远是原视频窗口：不抠像、不放大，窗口上方标题栏有 REC 红点和 `cam_01 REC`，四角取景框随音量脉冲。
- 节奏参考《做 PPT》全片：开头 12 秒内每 1–2 秒换一次位置；后段「直接跟它说」「接下来把需求交代清楚」「最关键的是」三处切回居中。

## 2. 《做 PPT》那一套动作（`talk.py`）

| 动作 | 函数 | 参数 | 音效 |
|---|---|---|---|
| 巨型输入框 | `prompt_box()` | 宽 1920 的圆角框，黄绿 6px 边；提示词 112px **跟着口播逐字打出**（字数按语音识别时间戳算）；真实标识符（作者名、项目名）下画黄绿线 + 小标注；打完后发送键变黄绿 | tick（每字） |
| 发送 | `plane()` | 纸飞机沿弧线飞到右上，0.5 秒，同时缩小 60% | whoosh |
| 三节点流程 | `pipeline()` | 下载 → 安装 → 验证；当前节点黄绿底、图标转动，完成的变描边 + ✓；箭头 `>>>` 逐个点亮；左下写真实快进倍率「×260」和 mm:ss | rush / shimmer |
| 转折句 | `speedlines()` + `mark()` | 人像居中时背后放射黄绿细线（每 0.1 秒换一组，强度 38%）；「划重点」红底白字斜章，从 1.6 倍砸下 | thump + shake |
| 数字滚动 | `count_up()` | 星标数/安装量从 0 滚到真实值，滚完变黄绿 | rush |

## 3. 《接 G站》那一套动作

| 动作 | 函数 | 参数 |
|---|---|---|
| 示波器 | `scope()` | 人像大窗正下方 40px：左 72% 宽是当前 0.05 秒的口播波形（黄绿 80%），右边 10 格音量条，下面一行 `mic · voice`。传入口播音频数组就是真波形 |
| 右栏打字 | `typed_lines()` | `[(开始时间, 文字, 颜色, 字号, 每秒字数)]`，正在打的那行末尾方块光标；红色行 = 痛点（「从头再教一遍 ×7」），配 `strike()` 划掉 |
| 拆解卡扇形展开 | `card_quad()` + `warp_card()` | 几张卡片带透视从一点扇形散开，每张对应口播里的一个词 |

《接 G站》那期背景还是纯黑；做 PPT 那期之后定了规矩：口播教程人像居中时背后不能空，要有动的背景（`dialp` 或 `ribbon`）。示范按新规矩用 `ribbon`。

封面用的是终端风「前后对比」版式（`cover_terminal.py` 的 `beforeafter`），见 `covers.md`。

## 4. 结构（3 段，45–75 秒）

| 段 | 画面 | 口播 |
|---|---|---|
| 开头 3 秒 | 人像居中 + 一句话钩子；或成品先行 | 开头照对标原文（平台查重看逐字稿，前 10–15 秒照抄，后面自己写） |
| step 01 为什么 | 左侧大窗 + 右栏讲解卡，或居中 | 痛点 → 这个东西能解决 |
| step 02 怎么装 | 小窗 + 巨型输入框 / 录屏 | 一句话怎么说、发出去会发生什么 |
| step 03 怎么用 | 小窗 + 录屏，结论句切回居中 | 真实效果 + 一句「为什么」（5–10 秒大白话） |
| 结尾 | 人像居中或清单 | 一句行动建议，念完就断 |

## 5. 被否掉的做法（别做）

- 背景：幻灯片墙、代码墙、网格地面（全被否），背景里的描边大字（被否，「不要文字，给我具体风格画面」）。
- 人像：抠像、放大、调色后期（PPT v3 的人像后期也一起被否了）。
- 封面：用视频截帧当人像（被否）。博主风封面的人像要用 AI 按本人照片生成棚拍半身照，表情克制。
