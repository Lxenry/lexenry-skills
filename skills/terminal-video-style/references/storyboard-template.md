# 分镜模板

> 复制这张表，一句口播一行。时间是剪好口播后的成片时间（秒）。
> 下面是示范片 `examples/demo_preview.mp4` 的分镜，对应 `templates/demo.py`（口播教程）。其他结构的分镜格式一样，只是「人像」一列换成该结构的固定元素（清单体写安装进度第几格，观点讲解写立方体状态）。

## 规格
- 3:4，2160×2880，30fps，约 6.4 秒
- 顶栏 `WORKBUDDY://DEMO`，3 段进度：装好 / 用起来 / 为什么
- 背景 dialp（表盘 + 稀疏粒子）

## 分镜

| 镜头 | 时间 | 口播 | 主视觉 | 关键词出口动作（时间） | 人像 | 音效 |

| S2 | 2.40–4.40 | 左边点「技能」，添加就装好了 | 录屏面板，推镜 1.0→2.2 倍到左栏；标题「专家·技能·连接器」 | 2.95「技能」打框；3.50 点击波纹；3.95「装好」盖章 ADDED + 震屏 | 无（真实项目放右下小窗） | whoosh 2.4 / tick 2.95 / pop 3.52 / thump 3.95 |
