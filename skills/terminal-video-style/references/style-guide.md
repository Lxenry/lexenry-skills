# 终端风短视频 · 风格手册（v1.0）

> 这份是「参数级」规范，写的是**所有结构共用的皮肤**：配色、字体、顶栏、字幕、后期、镜头密度、声音、发布。每种结构（preset）不一样的地方写在各自的 `preset-*.md`。
> 数字来自作者用这套风格做的全部作品（清单体 1 期、录屏教程 2 期、口播教程 2 期、观点讲解 1 期的分镜、合集封面）的渲染脚本，不是估计。
> 代码实现见 `templates/termstyle.py`（版式/动效/后期）、`templates/backgrounds.py`（背景）、`templates/sfx.py`（音效）、`templates/mix.sh`（混音）。
> 坐标都按 4K 画布（2160×2880）写；做 1080×1440 预览时所有数值 ÷2。

---

## 1. 一句话定位

整条视频像一台 AI 的工作屏幕：**黑底 + 唯一的酸性黄绿信号色 + 等宽字体系统信息 + 顶栏进度 + 逐字吐出的字幕**。每句话都有新画面，关键词出口那一帧必有动作。

同一套皮肤下有 4 种结构，按内容选：

| 结构 | 适合 | 手册 | 示范 |
|---|---|---|---|
| 清单体 | 盘点 N 个工具/技能 | `preset-listicle.md` | `demo_list.py` |
| 录屏教程 | 不露脸，一步步带着操作 | `preset-screen.md` | `demo_screen.py` |
| 口播教程 | 真人讲 + 录屏/动效 | `preset-talk.md` | `demo.py`、`demo_talk.py` |
| 观点讲解 | 讲一个方法/观点，主角是一句提示词 | `preset-concept.md`（按分镜收） | `demo_concept.py` |

另有两个跨结构的模块：核心句 3D 镜头（`module-core3d.md`）、封面（`covers.md`）。

## 2. 画布与规格

| 项 | 值 |
|---|---|
| 画幅 | 3:4 竖屏 |
| 母版 | 2160×2880，30fps，H.264 yuv420p，CRF 18 |
| 预览 | 1080×1440（lanczos 缩放） |
| 安全边距 | 左右 120px |
| 时长 | 教程建议 ≤ 90 秒；按口播语速约 5.7 字/秒估算 |
| 结尾 | 口播最后一个字念完 ≈0.1 秒就切，**不留尾巴、不放结束卡** |

## 3. 配色（只有这几种）

| 名称 | HEX | RGB | 只用于 |
|---|---|---|---|
| BG 底色 | `#050506` | 5,5,6 | 全片背景（不是纯黑） |
| FG 正文白 | `#F2F2EE` | 242,242,238 | 标题、字幕 |
| ACC 信号黄绿 | `#C8FF00` | 200,255,0 | **唯一强调色**：成功、重点、框、光标、进度、徽章 |
| ERR 红 | `#FF2E4D` | 255,46,77 | 只表示错误、被划掉、REC 红点 |
| DIM 次要灰 | `#77777D` | 119,119,125 | 顶栏、刻度、小标签 |
| DIM2 暗格 | `#26262B` | 38,38,43 | 未完成进度格、细框 |
| PANEL 面板 | `#0E0E10` | 14,14,16 | 卡片/窗口标题栏底 |
| GRAY 对比灰 | `#8A8F98` | 138,143,152 | 「之前/旧方案」那一侧 |
| 封面专用橙 | `#FF8000` | 255,128,0 | **只在封面**做关键词和四角星点缀，视频里不用 |

规则：一个画面里黄绿面积要小（框、线、字、光点），大面积永远是黑和深灰。不要引入蓝、紫、渐变彩色。

## 4. 字体

| 用途 | 字体 | 字号（4K） |

| 大标题（中文） | Noto Sans SC Black（900） | 200px（标题 > 8 字用 170） |
| 大标题（英文/数字） | Inter Black | 同上 |

中英混排时自动拆段：汉字走思源黑体，英文数字走等宽或 Inter（`termstyle.text()` 已处理）。

## 5. 版式（每一帧都有的固定层）

```
y=116–146  ● WORKBUDDY://主题              t+00:12.3     ← 顶栏：圆点 1.2Hz 闪，系统名 46px DIM，右侧计时
y=186–198  ███████  ███████  ░░░░░░░             ← N 格进度条，格间距 20px；已完成=黄绿，当前格加粗闪 2Hz（格数看结构：教程 3 段 / 8 步，清单体 N 项，观点讲解 3 个维度）
y=270      step 1/3                      装好     ← 40px DIM：左 step、右本段关键词
y=380      > step 01/03▌                          ← 60px 黄绿，0.25 秒打完，带方块光标
y=610      专家·技能·连接器                        ← 200px 白色大标题，每字 0.05 秒逐字出现
y≈760–2240 主视觉区（面板中心 y=1500，宽 1960）
y=2610     字幕（92px，居中，最多两行，行距 124）
```

- 顶栏系统名格式：`<产品名大写>://<本期主题大写>`，如 `WORKBUDDY://REMOTION`。
- 进度条：口播教程一般分 3 段（「为什么 / 怎么装 / 怎么用」之类），录屏教程按真实步骤数（安装教程是 8 步），清单体是 N 格安装进度，观点讲解是 3 格带名字（高度 / 深度 / 广度）。开头 intro 段 step=0。
- 标题跟着「这句话的关键词」换，不是整段一个标题；同一 step 内换标题时 tag 不重打。

## 6. 背景

| 结构 | 背景 |
|---|---|
| 口播教程 | 必须有动的图像背景：`dialp`（默认）或 `ribbon` |
| 录屏教程 | `dialp`（做数据动画那期）或纯黑 #050506（安装教程那期，录屏视窗已经占满画面） |
| 清单体 | 纯黑，画面信息已经很密 |
| 观点讲解 | 纯黑，主角是编辑器和立方体 |

**`dialp` 刻度表盘 + 稀疏粒子流**：
- 表盘：圆心 (1080, 1480)，5 圈刻度环，半径（1/4 分辨率下）280/360/450/560/690，刻度数 120/60/180/72/240，转速 +0.12/−0.08/+0.05/−0.03/+0.02 rad/s（内外圈反向）；每 5 格一根长刻度；一根指针光 1.2 rad/s 扫过。
- 粒子：1100 个小光点沿正弦流场从左下往右上流，带 3 帧拖尾，颜色 80% 黄绿 + 20% 青绿 (120,255,220)。
- 底：BG + 黄绿椭圆柔光（中心 (1080,1500)，半径 1100×1300，强度 4–5%）。

备选 **`ribbon` 流动光带**：4 组正弦光带、每组 18 根细线，位于 y=560/1500/2350/2650，缓慢起伏。

禁止：背景里放文字（描边大字、代码墙文字都被否过）；幻灯片墙、网格地面这类「通用科技模板」；星空/宇宙感背景（试过，被否了，保持终端风）；口播教程里人像居中时背后大片纯黑。

## 7. 后期（每一帧最后都过一遍 `post()`）

| 效果 | 参数 |
|---|---|
| 辉光 | **只给黄绿像素**（G>170、B<110、R<225）加：1/4 分辨率高斯模糊 σ6×0.55 + σ20×0.45 叠加。清单体不加（`post(bloom=False)`） |
| 扫描线 | 每 4 行里 2 行压暗到 94% |
| 暗角 | 亮度系数 clamp(1.12 − 0.55·d, 0.55, 1)，d 为到中心的归一化距离（半轴 0.75 画面） |
| 颗粒 | 1/3 分辨率高斯噪声 σ=5，6 张循环 |
| 故障切（换镜） | 换镜后 3 帧，强度 1→0：随机横条错位 ±90px + RGB 通道左右错开 16px |

## 8. 镜头密度（最重要的一条）

- **一句话一个主视觉**；同一个画面不变超过约 **3 秒** 就要换（推镜、换卡、打框都算变）。
- **关键词出口那一帧**必须有动作：打框、盖章、弹徽章、计数、扫光、划掉。动作起点对齐语音识别的逐字时间戳，不是按字数估。
- 人像（只有口播教程有）三种位置：
  - **左侧大窗**（《接 G站》）：912×1216 位于 (120, 840)，按原片 1:1 像素贴；右栏 x 1100–2040 放讲解卡/打字行；人像下方 40px 一条示波器（波形 + 10 格音量条 + `mic · voice`）。
  - **居中**（结论、转折、强调句）：原视频窗口 1296×1680，位于 (432, 730)，窗口外照样铺动态背景。
  - **右下小窗**（讲具体操作时）：456×608，位于 (1584, 2150)，主画面给录屏/动效；此时字幕排在小窗左边（y=2400）。
  - 居中↔小窗切换用 0.5 秒 ease-in-out 插值位置和大小。
- 人像 = 原视频画面，**不抠像、不放大**（只缩小），窗口上方 64px 标题栏：REC 红点 1Hz 闪 + `cam_01  REC`；四角取景框亮度随口播音量脉冲。
- 录屏：用原片，裁成只剩应用窗口；面板最多放大到原像素约 1.3 倍；鼠标替换成平滑白箭头 + 点击波纹；地址栏、IP、二维码、账号等隐私信息全部抹掉。
- 动效从真实素材里长出来（输入框放大成巨型输入框、录屏里的卡片原位浮起再放大），数据只用真实来源，示例数据要标「示例数据」。

## 9. 动效库（名字 = `termstyle.py` 里的函数）

| 动效 | 函数 | 时长 | 参数 | 配音效 | 什么时候用 |
|---|---|---|---|---|---|
| 打字标题 | `title()` | tag 0.25s + 每字 0.05s | tag 60px 黄绿、标题 200px 白 | — | 每个镜头开头 |
| 流式字幕 | `caption()` | 句长的 75% 内吐完 | 92px，末尾 42×102 黄绿方块光标 | — | 全片 |
| 打框 | `box()` | 0.2–0.25s | 线宽 8，黄绿，沿周长顺时针画出，外扩 10px | tick | 关键词对应的界面元素 |
| 四角取景框 | `ticks()` | 落位后出现 | 角长 36–60，线宽 5–7 | — | 主视觉落定 |
| 点击波纹 | `ripple()` | 0.3s | 两圈 r 20→110 / 10→70，渐隐 | pop | 每次点击 |
| 平滑鼠标 | `cursor()` | — | 白箭头黑描边，路径用 eio 缓动 | — | 录屏点击前 |
| 盖章 | `stamp()` | 0.2s | 从 2.2 倍砸到 1 倍，描边框 + 粗字，常配 `shake()` | thump + shimmer | 一步完成：ADDED / INSTALLED / 值钱 |
| 震屏 | `shake()` | 0.18s | 振幅 26px 线性衰减 | — | 盖章、砸字 |
| 徽章弹出 | `chip()` + `pop()` | 0.25s | 黄绿实底黑字 50–60px，带 18% 回弹 | pop | 产品名、标签 |
| 扫光 | `sweep()` | 0.5s | 宽 160 的白光带，模糊 σ40，叠加 50% | shimmer | 「核心词」出口时扫过卡片 |
| 黄绿闪 | `flash()` | 0.15–0.4s | 强度 0.35–0.5 衰减 | thump | 转折、核心句 |
| 划掉 | `strike()` | 0.2s | 红 #FF2E4D 线宽 8 | slash | 旧方法、错误做法 |
| 进度条 | `progress()` / `hud()` | 跟随实际进度 | 细条 14px，右端百分比 | rush | 下载/安装/生成；快进镜头标「×260」与真实耗时 |
| 卡片透视飞入 | `card_quad()` + `warp_card()` | 0.4–1.9s | yaw 0.20→0.03、pitch 0.10→0，带投影和 18% 黄绿外发光 | whoosh | 成品、截图、录屏面板入场 |
| 录屏推镜 | `panel_view()` | 0.5–0.7s | z 1.0→2.2，eio 缓动，对准要讲的位置 | whoosh | 讲某个按钮/菜单 |
| 数字弹出 | `poptext()` | 0.25s | 60%→100% 带回弹 | pop | 数字、结论词 |
| 故障切 | `post(glitch=)` | 3 帧 | 见第 7 节 | whoosh | 换镜 |

缓动：出场用 `ease`（三次缓出），移动/推镜用 `eio`（三次缓入缓出）。不要用线性移动。

## 10. 字幕

- 文本来自语音识别逐字时间戳（推荐 sherpa-onnx SenseVoice，离线可跑），**以实际念的为准**，不按稿子。
- 每句在「句长的 75%」内逐字吐完（最少 0.25 秒），英文单词整词出现。
- 末尾黄绿方块光标：吐字时常亮，吐完后 2.2Hz 闪。
- 每行最多 1900px 宽，超了断成两行（在标点或「的了把和」处断，两行尽量等长）。
- 字幕下垫一条上下渐隐的暗带（压暗 55%，小窗模式 70%），保证在动态背景上可读。
- 产品名、核心词在字幕里换成黄绿（`hl={"WorkBuddy": ACC}`）。
- 平台敏感词（如抖音上「GitHub」会被限流）字幕和画面里改写成「G站」，口播不用改。

## 11. 声音

| 层 | 规则 |
|---|---|
| 口播 | 原声或你自己的声音；剪掉重说和废段，长停顿压到 0.32 秒；最后一个字念完 0.1 秒切 |
| 人声处理 | 85Hz 高通 → 250Hz −1dB → 3.5kHz +1.75dB → 8kHz 高架 +1dB → 压缩 3.2:1（阈值 −21dB）→ −14.5 LUFS |
| BGM | 暗色电子/低频氛围；3.5kHz −2.5dB 让位，−32 LUFS，人声说话时侧链压低（ratio 3） |
| 音效 | 全部代码合成（`sfx.py`），音量 0.92，和画面动作同一帧 |
| 成片 | **约 −15 LUFS**，真峰值 ≤ −1.5 dBTP，limiter 一定要 `level=0`；末尾 40ms 淡出防爆音 |

音效对应：whoosh=换镜/飞入，pop=弹出/点击，thump=盖章/砸字，shimmer=完成/高亮，rush=快进，slash=划掉，tick=打字（每字一下，间隔 0.24–0.3 秒）。

## 12. 口播写法（风格的一部分）

- 开头一句就给结论或钩子，标题和开头要对得上内容。
- 每期留一句大白话的「为什么」（5–10 秒），不说「底层逻辑」四个字；要么前面埋钩子结尾兑现，要么压在证据镜头上说，说完就结束。
- 钩子要兑现：视频里说了什么，就在画面里证明、在评论区真给。
- 数据和证据只用真实来源（README 徽章、实际耗时、真实录屏），不编。

## 13. 封面

三类版式，全部一次出三种比例（3:4 1080×1440、4:3 1440×1080、16:9 1920×1080），细节见 `covers.md`：

| 类 | 脚本 | 用在 |
|---|---|---|
| 终端风（4 种主视觉：字符粒子大数字 / 斜放截图 / N 格面板 / 前后对比框） | `cover_terminal.py` | 清单体、安装教程、接 G站、合集 |
| 博主风（厚描边大字 + 撕纸条 + 截图道具 + 右下人像） | `cover.py` | 做 PPT |
| 叙事型（草图/终端 → 速度线里冲出成品，不用人像） | `cover_story.py` | 做数据动画 |

博主风版式：左上两行厚描边大字（黑描边 = 字号 8.5%、黑投影偏移 6%/7.5%、整体旋转 −4°），第一行产品名黄绿 Inter Black，第二行白字 + 关键词橙色；下面一条斜贴 +3° 的米白撕纸条（#F7F3E9，黑字 + 橙色关键词）；左下 3 张本期真实截图扇形叠放（白边 7px、各转 −13°/−3°/+7°）；黄绿圆章（数字 + 小字）；右下半身人像，人像后一团黄绿柔光；四角星点缀（橙 + 黄绿）。
- 底：#111 深色颗粒 + 右上黄绿网点 + 暗角。
- 人像：不要视频截帧。用 AI 按本人照片生成棚拍半身照（黑 T、明亮柔光、表情克制：嘴角微扬不露齿），**纯绿幕背景**，`cover.py` 自动抠像。

## 14. 发布物料（每期一个 `发布/` 文件夹）

`最终成片（带版本号）+ 发布文案.md + 三种封面`，只放这一个视频，防止传错。

| 平台 | 要写 |
|---|---|
| 抖音 | 标题 ≤30 字、简介、话题 tag |
| 视频号 | 短标题 ≤16 字且无标点、标题/描述首行、简介、话题 tag |
| 小红书 | 标题 ≤20 字、正文 ≤1000 字（分段、少量 emoji）、正文末尾 #话题 |

封面 3:4 给三个平台竖版，4:3 / 16:9 给横屏入口。
