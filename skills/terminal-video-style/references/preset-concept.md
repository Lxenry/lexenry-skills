# Preset：观点讲解（主角是一句提示词）

> 适合：讲一个方法或观点，比如「提示词的高度、深度、广度」「怎么写需求」「为什么 X 比 Y 好」。观众记住的应该是「改前 / 改后」。
> 来源：作者《提示词三维度》，约 112 秒。
> **这一份是按分镜收的**：那期的成片交给 Codex 做，风格包作者手里没有成片。所以这里的组件和尺寸来自分镜规格（分镜按 1080 宽写，这里 ×2 换到 4K），没有对着成片逐帧核对过。用的时候先出关键帧看效果。
> 皮肤照 `style-guide.md`。代码在 `templates/prompt_kit.py`，示范在 `templates/demo_concept.py`。

---

## 1. 形式

- 主角是**一个提示词编辑器（Composer）**，全片反复出现：旧写法打进去 → Diff 改写（红删绿写）→ 下方输出卡对比。
- 「三个维度」画成**三根坐标轴**：Y = 高度（往上拔）、Z = 深度（往里钻）、X = 广度（往两边展开）。讲到哪个维度，中间那个小立方体就沿哪根轴拉长；总结时变成满格实心。
- 顶部常驻 **3 格带名字的进度**（高度 / 深度 / 广度），讲完一段填满一格，相当于清单体的 N 格安装进度。
- 不用 AI 第一人称（这是人在讲观点）；终端元素只做点缀（文件名标签、状态行），不做主体。
- 背景纯黑；右上角常驻账号名（等宽 44px 灰）。

## 2. 组件（`prompt_kit.py`）

| 组件 | 函数 | 规格（4K） |
|---|---|---|
| 3 格进度 | `hud_named()` | 每格 360×20，格上方写维度名；讲完填满黄绿，正在讲的那格闪 |
| 编辑器 | `composer()` | 圆角 24，底 #111113，3px #2A2A2A 边；左上文件名 `prompt.txt`，右下「发送 ↵」 |
| 打字 | `type_line()` | 18 字/秒，带打字音，末尾黄绿方块光标 |
| Diff 改写 | `diff()` | 旧行前缀 `-`、红色、删除线、降到 40% 并上移让位；新行前缀 `+` 黄绿逐字打出。旧行不消失，方便对比 |
| 输出卡 | `output_card()` | 旧输出灰色、模板化；新输出边框变黄绿，右上 `✓ upgraded`。内容只放占位文字看结构，不编数据 |
| 三轴立方体 | `axis_cube()` | 等距投影线框；三根轴念到维度名那一帧点亮（配「嘀」）；内部黄绿半透明立方体可沿单轴缩放；`solid=1` 变实心 |
| 印章 | `stamp()`（termstyle） | `2024` 红章砸在旧写法上；`可直接投递` 黄绿章砸在成果上 |
| 文字名片 | `name_card()` | 引用别人的观点时用：Inter Black 名字 + 机构小字，**不用照片、不用 logo** |

## 3. 结构（3 个维度，约 110 秒）

| 段 | 画面 |
|---|---|
| 开场（锁定原文） | 黑屏中央只有编辑器 → 打出旧写法 →「2024」红章 + 整行划掉 + `deprecated` 灰标签 → 文字名片说明观点出处 |
| 引出三维度 | 编辑器缩成小立方体，进入三轴；念到三个词，三根轴依次点亮；顶部 3 格出现 |
| 每个维度 ×3（约 28 秒） | 节拍 1：标题页（`0N / 03` + 维度大字 + 方向箭头），HUD 对应格闪 → 节拍 2：旧写法打出 + 旧输出 → 节拍 3：Diff 改写 + 新输出 + 一个可视化（倒计时圆环、文件落下变附件、指标树往下钻、动作时间线）→ 节拍 4：印章 + 立方体沿该轴拉长 + HUD 格填满 |
| 总结 | 立方体居中变满格实心，三句话从三根轴末端依次打出，每句约 1.3 秒，前一句不消失 |
| 结尾 | 中央一个通用评论输入框（不仿任何平台界面），placeholder「你最常用的一句提示词…」，念完就断 |

超过 6 秒的镜头内部拆 2–3 个节拍，画面不停。

---

## 4. 声音

- 讲解语气，正常语速，段间不留长停顿；建议按「开场 / 维度 1 / 2 / 3 / 结尾」分 5 段录，方便卡点。
- BGM 和清单体同一路暗色电子，慢一点（96–100 BPM），每个维度的标题页加一记重拍，总结段起鼓。
- 新增音效：文件落地「咚」、标签贴上「咔」、深度下沉的低频「咚」。

## 5. 不要用

被引用人的照片、访谈画面、个人网站截图、公司 logo（肖像权和商标），抖音、视频号、微信的真实界面仿制。
