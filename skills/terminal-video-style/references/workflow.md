# 从口播到成片的流程

> agent 照这个顺序做。每一步的产出写在括号里。

## 0. 先选结构
清单体 / 录屏教程 / 口播教程 / 观点讲解，选法见 SKILL.md 第一步。下面的流程四种结构都一样，区别只在第 3、5 步用哪个 preset 手册和哪个示范脚本当起点。

## 0.5 准备（人做）
- 口播稿（约 5.7 字/秒估时，教程 ≤ 90 秒）。
- 口播录音（录屏教程、清单体、观点讲解只要声音）或口播视频（口播教程）：后置主摄 4K、锁曝光对焦、关美颜；补光灯放侧前 45° 略高于眼睛（戴眼镜避开反光）；身后约 1 米挂深灰纯色布；原片别经微信/飞书转发（会被压到 540p）。
- 录屏：只录要用的步骤，每个关键界面停 1–2 秒；之后裁成只剩应用窗口。
- 本期真实产出（成品文件、截图）。

## 1. 语音识别拿逐字时间戳（asr.json）
- 推荐 sherpa-onnx + SenseVoice int8 模型（离线、CPU 能跑，模型在 k2-fsa/sherpa-onnx 的 GitHub releases 里）。
- **字幕和卡点都按逐字时间戳对齐，不按字数估**（估算会差 1–2 秒）。

## 2. 剪口播（voice_cut.wav + edl.json）
- 剪掉重说、口误、废段；超过 0.32 秒的停顿压到 0.32 秒（核心句前可以留 0.6 秒）。
- 最后一个字能量消失后 0.1 秒切。
- 记录剪辑表（源时间 → 成片时间），后面所有时间都用**成片时间**。

## 3. 写分镜（storyboard.md，模板见 storyboard-template.md）
- 一句话一行：成片时间、口播、主视觉、关键词出口时的动作、人像状态（居中/小窗/无）、音效。
- 自查：有没有哪一段同一画面超过 3 秒？有没有关键词没有动作？有没有大片空黑？

## 4. 先出样张再做全片
- 每个镜头先出 1 帧 4K 关键帧（`ONLY=秒数 python3 你的脚本.py`），拼成一张总览给人看。
- 关键镜头（开头 3 秒、核心句证据镜头）一次出 3–5 个差异明显的版本让人挑。
- 逐镜头预览用 1080×1440，定稿后再出 4K。

## 5. 渲染（out/ALL/%04d.png）
- 每个镜头一个函数 `S01(t) … SNN(t)`，返回 RGB 帧；顺序：背景 → 素材/面板 → PIL 画文字和动效 → 字幕 `caption()` → 后期 `post()`。
- 4 进程并行：`for k in 0 1 2 3; do CHUNK=$k/4 python3 xx.py & done; wait`。4 核 CPU 上 4K 约 3 秒/帧/进程。

## 6. 音效 + 混音（mix.wav）
- 音效事件写成 `[["whoosh", 2.40], ["tick", 2.95], ...]`，`python3 sfx.py events.json 时长`。
- `bash mix.sh voice_cut.wav sfx.wav bgm.wav mix.wav`，检查输出 I ≈ −15 LUFS。

## 7. 编码
- 4K 母版：`SIZE=2160:2880 bash render.sh out/ALL 成片_v1_4K.mp4 mix.wav`
- 预览：`bash render.sh out/ALL 成片_v1_预览.mp4 mix.wav`
- 版本号只加不覆盖：v1、v2…

## 8. 交付前检查清单
- [ ] 最后一个字念完就结束，没有尾巴
- [ ] 每 3 秒内画面有变化，关键词都有动作
- [ ] 口播教程：没有大片纯黑，背景一直在动；人像没被放大、没被抠像
- [ ] 清单体：顶栏 N 格走到 N/N，结尾说的关键词评论区真的有
- [ ] 用了核心句 3D 镜头：碎裂和落位两个瞬间分别卡在转折字、结论词上
- [ ] 字幕和实际口播一致，敏感词已改写
- [ ] 录屏里没有地址栏、IP、二维码、账号、私信等隐私
- [ ] 数据有真实来源，示例数据有标注
- [ ] 响度约 −15 LUFS，无爆音
- [ ] 发布/ 里只有一个成片 + 发布文案 + 三种封面（封面版式见 covers.md）
