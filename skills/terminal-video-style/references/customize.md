# 改成你自己的风格

先说结论：这套风格能留住人，靠的是**节奏和结构**（一句一画面、3 秒必变、关键词出口有动作、顶栏进度、口播教程里人像居中/小窗交替、念完就断），不是黄绿这个颜色。所以建议**节奏规则原样照搬，皮肤换成你自己的**，不然群里十个号做出来一模一样，平台和观众都分不出谁是谁。

## 一、建议保留（换了就不是这套方法了）
- 镜头密度：一句话一个主视觉，同一画面不超过 3 秒（style-guide 第 8 节）
- 关键词出口那一帧有动作，时间对齐语音识别的逐字时间戳
- 固定层结构：顶栏进度 → step tag → 逐字大标题 → 流式字幕
- 口播教程的人像用原视频窗口，不抠像、不放大
- 念完最后一个字就结束；成片约 −15 LUFS

## 二、换皮肤：改哪里

| 想改的 | 改哪个文件、哪一行 | 说明 |
|---|---|---|
| 信号色 | `templates/termstyle.py` 的 `ACC = (200, 255, 0)` | 只改这一行，框、光标、进度条、徽章、背景、辉光会一起变（辉光已按颜色距离自动挑像素）。效果见 `examples/frames/custom_color_example.jpg`（换成青色 0,200,255）。选饱和度高、和黑底反差大的颜色；红色已经被「错误/划掉」占用，别用 |
| 底色 | `BG = (5, 5, 6)` | 保持接近黑，深灰/深蓝都可以；浅色底会让辉光和扫描线失效，要换就得重调后期 |
| 顶栏系统名 | 每期脚本里 `ts.HUD_NAME = "XXX://主题"` | 换成你的账号名或产品名，是最便宜的辨识度 |
| 进度条段数 | `hud(..., nsteps=3)` | 你的教程如果固定是 4 步就改 4 |
| 背景 | `backgrounds.py` 的 `STYLES`，脚本里 `BGSTYLE=ribbon` 切换 | 自带 6 种：dialp（表盘+粒子，默认）、dial、particles、tracks、aurora、ribbon。新写一个函数 `bg_xxx(t)` 返回 RGB 帧，加进 `STYLES` 就能用。规则：图像、会动、不放文字 |
| 字体 | `termstyle.py` 的 `FP` | 等宽字体换成别的等宽（如 Fira Code、Sarasa Mono），中文换成你有授权的黑体。商用字体自己装，不要放进要分享的包里 |
| 盖章文字、徽章样式 | `stamp()`、`chip()` 的参数 | 例：`ADDED` 换成中文「装好了」 |
| 封面 | `examples/covers/*.json` 复制一份改文字；颜色在 `coverkit.py`（终端风、叙事型）和 `cover.py`（博主风）顶部的 `LIME / ORANGE`，封面不读 `termstyle.ACC`，换色要两边都改 | 版式可以留，配色和人像换成你的 |
| 音效 | `sfx.py` 里每种音效是一个函数 | 改频率/包络就有自己的声音标识；或者换成你有版权的音效文件 |
| BGM | `mix.sh` 第三个参数 | 用你自己有版权的 |

## 三、让 agent 帮你改
直接对 agent 说，例如：
> 用 terminal-video-style 技能，但信号色换成 #00C8FF，顶栏名 MYNAME://，背景用 ribbon，盖章字改中文。其他规则不变。先出一张关键帧给我看。

## 四、不要改坏的地方
- 改颜色后让 agent 跑 `ONLY=3.6 python3 demo.py` 出一帧，确认框和字幕光标都变色、辉光还在。
- 不要把字号整体调小：4K 下 92px 字幕、200px 标题是手机上能看清的下限。
- 不要关掉 `post()`，没有扫描线和颗粒，画面会显得很「电脑生成」。
