# Preset：录屏教程（不露脸，录屏当主画面）

> 适合：一步步带着操作的教程，人不出镜，只有口播声音。
> 来源：作者两期作品。
> - 《WorkBuddy 安装教程》：8 步，211 秒，纯黑底。录屏视窗占满中段，推镜跟随，框外压暗高亮，结尾是 `[✓]` 清单。
> - 《WorkBuddy 做数据动画》：3 步，64.6 秒，背景用 `dialp`（表盘 + 粒子）。录屏和代码画的数据对比交替出现，核心句配 3D 证据镜头（见 `module-core3d.md`）。
> 皮肤（配色、字体、顶栏、字幕、后期、声音）照 `style-guide.md`，这份只写结构上不一样的地方。
> 代码在 `templates/screen.py`，示范在 `templates/demo_screen.py`。

## 1. 和口播教程的区别

| | 口播教程 | 录屏教程 |
|---|---|---|
| 人像 | 原视频窗口，居中和小窗交替 | **没有** |
| 主画面 | 录屏、动效、人像轮流 | **录屏视窗常驻**，中间插代码画的数据/对比画面 |
| 步骤数 | 一般 3 段 | 按真实步骤走（安装教程 8 步，数据动画 3 步），顶栏格数 = 步骤数 |
| 背景 | 必须有动的背景 | 纯黑或 `dialp` 都行（录屏视窗已经占了画面大半） |
| 标题 | 200px | 184px（视窗要往上挪） |

## 3. 录屏视窗的 5 个动作（`screen.py`）

| 动作 | 函数 | 参数 | 什么时候 |
|---|---|---|---|
| 推镜跟随 | `keyed()` + `View()` | 关键帧 `(t, cx, cy, zoom)`，录屏坐标；两键之间只在**最后 0.6–0.7 秒**缓动，其余时间停住 | 口播提到哪个区域，镜头提前 0.7 秒开始推过去 |
| 框外压暗 + 高亮框 | `put_view(spot=)` + `spot_box()` | 框外压暗 58%，0.25 秒淡入；黄绿 8px 圆角框 + 两圈外发光 | 关键词出口那一帧 |
| 平滑鼠标 + 点击 | `cursor()` + `ripple()` | 鼠标路径 0.55 秒 eio；点击处双圈波纹 0.3–0.6 秒 | 每次点击（原录屏鼠标要先抹掉） |
| 标签 | `callout()` | g 黄绿底黑字（正向）/ r 红底白字（错误）/ k 黑底黄绿框（中性），从下 16px 滑入 0.22 秒 | 「点这里」「这次的材料在这」「时间是不是编的」 |
| 视窗角标 | `badge()` | 视窗右上，黑底黄绿等宽字 | 「快进 ×260」「已装好」「网址」 |

另有 `ring()`：脉冲圈，r 76±12，用来提示「看这里」但还不点的位置。

## 4. 数据对比画面（《做数据动画》）

录屏讲的是「怎么做」，数据画面讲的是「做完省了多少」。两种画法：

| 画法 | 函数 | 节奏 |
|---|---|---|
| 两个表盘 | `gauge()` | 使用前灰、使用后黄绿；指针 0.8 秒转到读数，下面 130px 等宽读数跟着涨 |
| 双时间轴 | `compare_bars()` | 刻度轴 0.3 秒画出 → 两条线从同一个 0 点一起往右跑 1.2 秒，短的先停 → 括线 0.3 秒画出 → 「省 X 小时」弹出 |

- 数字不是真实测量的，右上角必须挂 `sample_tag()`「示例数据」。
- 数据画面放在 `card()` 深色卡里，卡外照样是背景。

## 5. 结构（以 8 步、约 3 分钟为例）

| 段 | 画面 | 口播 |
|---|---|---|
| 开头 0–5 秒 | 成品先行：最终做出来的文件/画面直接给（`demo.py` 的 S1 写法） | 「从下载开始，做出第一份能用的文件」 |
| 步骤目录 | `01–0N` 编号清单，右侧黄绿括号「装好 · 用上」 | 「一共 N 步，前 X 步装好，后面用上」 |
| 每一步 | 标题 `> step 0n/0N` + 录屏视窗；每句一个动作（推镜/高亮/点击/标签） | 你点哪里、看到什么、为什么 |
| 结尾 | `checklist_end()`：`[✓]` 逐行 0.12 秒打出 → 整条黄绿 CTA | 一句行动建议，念完就断 |

> 安装教程那期有 211 秒，作者事后在开头加了一条提示「已经装好？直接拖到 0:49」，让已经装好的人跳过前面。建议录屏教程控制在 90 秒内，步骤多就拆成合集。

## 6. 录屏处理（必须做）

- 裁成只剩应用窗口；地址栏、IP 提示、二维码、账号、私信全部抹掉。
- 原鼠标抹掉，换成 `cursor()` 平滑箭头 + `ripple()`。
- 录屏最多放大到原像素约 1.3 倍（`View` 的 zoom 是裁切推近）。
- 等待过程（下载、安装、生成）用真实录屏快进，角标写真实倍率和真实耗时，不剪掉不造假。
