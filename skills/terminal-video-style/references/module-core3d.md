# 模块：核心句 3D 镜头

> 来源：作者《做数据动画》那期给核心句做的镜头。核心句是「AI 时代，动手越来越便宜，值钱的是你知道自己要什么，并且能说清楚」，镜头约 5 秒，那期把它定为「这一期要超越对标的地方」。
> 代码在 `templates/core3d.py`（类 `Core3D`），示范在 `templates/demo_core3d.py`，对照图是 `examples/compare_core3d.jpg`（当前包未附此模块的示范视频）。
> 任何结构都能插。条件是这一期有一句金句，并且有一个「说 → 做出来」的证据可以画。

---

## 1. 它在画什么

一句话里通常有一个转折：前半句是「便宜的 / 旧的」，后半句是「值钱的 / 新的」。镜头把转折变成一次物理变化：

| 时刻 | 画面 | 卡在口播的哪个字 | 音效 |
|---|---|---|---|
| 0–0.26s | 草图板从远处（z 5200）转着飞进 3D 空间（转 0.95 rad 回正） | 句子开头 | whoosh + thump |
| 0.35–1.6s | 光笔沿笔画描出草图（笔头白点 + 16 个黄绿火星），线条带辉光 | 前半句 | tick |
| **碎裂** | 草图碎成 28000 个粒子 + 线条碎片，向四周炸开后减速，相机绕到侧面形成定格环绕 | **转折字**（原片是「便宜」的「便」） | slash + thump，震屏 22px，色散 12px |
| 穿越 | 粒子和碎片带拖影一起飞向远处（z 3000），相机跟着穿过去，轻微侧倾 | 后半句前段 | rush |
| **落位** | 粒子落到成品的亮像素上拼成成品，冲击波环扩散，闪 + 震屏 44px，色散 22px | 后半句的**结论词** | thump + shimmer |
| 结尾 | 相机继续缓推 90，念到最后关键词再震一次 18px | 最后的关键词（原片是「说清楚」） | thump |

## 2. 怎么用

```python
from core3d import Core3D
core = Core3D(board, strokes, product, anchors=(t0, t_break, t_fly, t_land, t_end), bgf=STYLES["dialp"])
frame = core.frame(t)     # 4K RGB，不含顶栏/标题/字幕，外面照常叠 hud()、title()、caption()、post()
```

- `board`：草图板贴图（宽 2160、高约 1500、暗底），放坐标轴、标签这些静态部分。
- `strokes`：光笔要描的笔画，写成草图板像素坐标的折线列表。粒子从笔画上发射，碎片也由笔画切出来。笔画越长，碎片越多。
- `product`：成品图（宽约 2000、暗底亮内容）。粒子会落到亮度大于 55 的像素上。最好用本期真实成品的一帧。
- `anchors`：5 个成片时间点，依次是镜头开始、碎裂、开始穿越、落位、结束，全部取语音识别的逐字时间戳。原片间隔是 1.65 / 1.2 / 1.02 / 1.19 秒，中间的所有节拍按这 5 个点分段线性映射，所以直接填你自己的字的时间就行。
- `demo_assets()` 给了一套示例（两条时间线草图 → 黄绿成品图），可以照着换。

## 3. 注意

- 这是「超越点」镜头，一期最多用一次，放在核心句上。用多了就不稀奇了。
- 渲染重：4K 一帧约 2–10 秒，粒子越多越慢。先用 `ONLY=秒数` 出碎裂、穿越、落位三帧看。
- 作者试过「星空 / 宇宙」方向（黑底像宇宙、粒子像星星），被否了。保持终端风：表盘背景 + 黄绿粒子，不要加星云和蓝紫色。
- 做这个镜头时作者的流程是一次出 3–5 版差异明显的给人挑（碎裂定格、微距一镜到底穿越、原编排只升级质感……），最后挑中两版合成了这个 L 版。你做自己的版本也建议这样来。
