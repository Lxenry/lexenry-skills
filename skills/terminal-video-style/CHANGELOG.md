## v1.0（2026-11-20）
重做。v0 / v0.1 只从部分作品里提炼，这一版把作者用这套风格做过的作品逐期过了一遍（分镜、渲染代码、成片、封面），所有用了这套风格的都算样本，不按播放量挑。
- 结构从 2 种扩到 4 种，平等并列，按内容选：
  - 清单体（8 个 skill）：原有，手册去掉了按播放量排序的说法。
  - **录屏教程**（新增，来自安装教程 + 做数据动画）：`references/preset-screen.md`、`templates/screen.py`、`demo_screen.py`。录屏视窗、推镜跟随、框外压暗高亮、鼠标/点击、标签、视窗角标；表盘和双时间轴数据对比；`[✓]` 结尾清单。
  - **口播教程**（补齐，来自接 G站 + 做 PPT）：`references/preset-talk.md`、`templates/talk.py`、`demo_talk.py`。左侧大窗 + 示波器 + 档案卡、巨型输入框逐字打出、纸飞机、三节点流程 + 快进倍率、速度线 + 划重点章、数字滚动。
  - **观点讲解**（新增，来自提示词三维度的分镜）：`references/preset-concept.md`、`templates/prompt_kit.py`、`demo_concept.py`。编辑器、Diff 改写、输出卡、三轴立方体、3 格带名字进度。那期成片不在作者手里，按分镜收，已注明。
- **核心句 3D 镜头**（新增，来自做数据动画的定稿 L 版）：`references/module-core3d.md`、`templates/core3d.py`、`demo_core3d.py`。草图碎裂定格 → 3D 穿越 → 粒子落位成成品，5 个锚点对齐你自己的口播。
